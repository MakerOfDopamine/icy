# ICY

This is a very ironic name for the game, because the mechanics are basically the opposite of the ground being icy.
I named this repo while I still had another idea and then realized that not only was the idea really hard, I also wasn't motivated to make it.
So I made this abomination instead.

With all that said, this is a very (and by that I mean VERY) simple game made for Jumpstart so I can go on to do my spreadsheet work in budgeting for the Haven event(tm).
The core mechanic is that you cannot "move" horizontally unless you are in the air somehow. This makes it so that adjustments are more difficult than usual and I spent several hours puzzling over how to make good level design that utilises the gimmick without seeming boring.

Play at: https://makerofdopamine.itch.io/icy
